HOK — Agency Operations Platform

Requirements Summary  ·  Version 0.3 (decisions included)  ·  13 Oct 2026

What are we building? One website with two sides. The public side is the firm’s portfolio. The private side lets the firm manage its clients, plan events & shoots, keep content links in one place, share a live dashboard with each client, and assign tasks to the team.

The main problem it solves: no more lost Drive links, missed shoots, or client feedback buried in chats.

1. Who uses it?

UserWhat they do
AdminControls everything. Sees all clients & all data. Creates staff accounts and stage templates. The only one who assigns tasks. Can also have their own clients.
Social Media ManagerManages their own clients: events, calendar, content links, client comments. Gets tasks from Admin.
Marketing ManagerSame as Social Media Manager.
Marketing Agent, Developer, EditorTasks only: receive tasks from Admin, update the status with comments, and mark them done.
Client (outside)No login. Opens a private link to see their dashboard and leave comments.

🔒 Privacy rule: a manager sees only their own clients. Nobody else can see them except Admin. One client = one manager.

3. Main features

1Client Profiles

  • Business name, logo link, contact, social handles, services, time zone, notes
  • Each client belongs to one manager
  • Admin can move a client to another manager

2Events & Shoots

  • Shoot, campaign, meeting… with date, time, time zone, place
  • Admin makes stage templates (e.g. “Photo Shoot”: Planned → Shoot → Editing → Client Review → Completed)
  • Manager picks a template when creating the event; its stages are used as they are

3Content Links (Assets)

  • Paste a link (Drive, Dropbox, Canva…). No file upload
  • Add type (photo / video / doc), a comment and tags
  • Search by tag or comment, so you never lose where content is
  • Internal only. Clients don’t see these

4Calendars

  • Client calendar: all events of one client
  • My calendar: all my clients’ events + my own events
  • Admin calendar: whole company
  • Works across time zones: everyone sees times in their own zone

5Client Portal (shared link)

  • Manager creates a private link for the client. No PIN, no login
  • Client sees: current event & its stage, upcoming events, calendar
  • Link can be turned off or replaced anytime. Simple plain design

6Client Comments

  • Client writes a comment from the portal
  • Only that client’s manager gets a push notification
  • Manager sets status: Received → In Progress → Solved and can reply

7Team Tasks

  • Admin gives a task to one staff member
  • Staff updates the status with a comment: To Do → In Progress → Done (or Blocked). They close it themselves
  • Admin is notified of every update and can reopen

8Editor Tasks (extra fields)

  • Raw files link (Google Drive)
  • Reference edit link (the style to follow)
  • Script

9Notifications

  • Phone/browser push + bell icon in the app
  • For: new client comment, new task, task update (event reminders later)
  • On iPhone: add the site to the Home Screen to get push

10Dashboards

  • Each user sees a home screen made for their role
  • Today’s events, pending comments, due tasks, progress at a glance

4. How it works: examples

New client

Manager adds client→Creates portal link→Sends link to client on WhatsApp

Shoot day

Create event, pick “Photo Shoot” template→Shows on calendars & portal→Stage moves to “Editing”→Client sees progress

Saving content

Files are in Drive→Manager pastes link + tags “reel”, “diwali”→Found later by tag search

Client feedback

Client comments “change music”→Manager gets push→In Progress→Solved + reply

Editing task

Admin assigns “Edit reel” + Drive link, reference, script→Editor updates status + comment→Editor marks Done→Admin notified
